# تقييم قدرات التشغيل

## محاولات فعلية

- لا KVM أو vmx/svm متاح للفحص؛ `emulator -accel-check` أعاد 3. توافر Docker لا يمنح تسريعًا افتراضيًا؛ لا صور/حاويات Android جاهزة عند الفحص.
- نُزل Emulator 37.3.4 وplatform-tools 37.0.1 وصورة AOSP Android 15 / API 35 x86_64 من Google، وتطابقت الأحجام وSHA-1 المنشور لكل أرشيف عبر metadata موثوقة وTLS. البصمات هنا لفحص سلامة التنزيل وليست بديلًا عن توقيع APK.
- بدأ محاكي جديد مع TCG وSwiftShader، دون نافذة أو snapshots، وبذاكرة 3072 MiB ونواتين. اضطُر إلى ANDROID_I_WANT_MY_TCG=yes بعد رسالة الأداة الدالة على ذلك.
- adb الأصلي تعذر تشغيله لعدم القدرة على إنشاء ~/.android في filesystem للقراءة فقط؛ استُخدم بديل adb-shell محلي ومفتاح اختبار مولد خارج المستودع. صورة AOSP الاختبارية قد لا تطلب مصادقة adbd؛ لم يُتجاوز تحكم التطبيق أو تسجيل الدخول.
- منافذ emulator/ADB 5554 و5555 مقيدة بـ127.0.0.1 و::1. لم تُفتح للإنترنت.
- أضيفت قواعد IPv4/IPv6 داخل الجهاز ترفض OUTPUT خارج loopback قبل محاولة تثبيت التطبيق، لمنع الاتصال بإنتاج أو أي backend. لا يُعد فشل شبكة في هذا الوضع عيب backend.
- محاولة pm install المبكرة قبل اكتمال boot أعادت NullPointerException داخل PackageManagerInternal؛ عائق تهيئة Android، وليس انهيار Sales Pro. لم تُعد نفس المحاولة إلا بعد انتظار تغير حالة الإقلاع.

## النتائج الوظيفية

السجل النهائي للمحاولات ونتيجة التثبيت/الإطلاق ومشاهدة الشاشات في `sales_pro_e2e_20261017_225758/runtime_and_crashes_ar.md`. لا تعتمد نتائج UI على هذا الملخص الأولي؛ ملفات evidence في مجلد E2E هي مرجع التنفيذ الفعلي.

وفر المستخدم حسابًا نهائيًا وأدخل حرفيًا عبر UI وقدّم النموذج؛ أوقفه التحقق المحلي «اختر الفرع والسنة المالية». الحساب ليس متطلبًا مفقودًا الآن. لا جلسة مصادق عليها ولا هوية TEST متحققة باستجابة backend. لم تنفذ عمليات عملاء أو مالية.

## النتيجة النهائية

نجح التثبيت بعد اكتمال boot وظهرت واجهات الترحيب الأربع ثم الدخول فعليًا. عاد النموذج بعد Back وإعادة الفتح، والعربية/اكتمال الترحيب مستمران دون clear-data. رُصد PID وشاشة فعلية ولا crash لحزمة Sales Pro في النافذة؛ توجد أعطال System UI وBluetooth وقيود سرعة TCG منفصلة.

أزيلت قواعد العزل الخاصة بنا فقط واستُخدم الوكيل الموروث الصحيح. المنافذ5554/5555/5037 محلية فقط. adb الرسمي شغل في حاوية محلية لعلاج مجلد المستخدم غير القابل للكتابة، مع إبقاء السياسة دون bypass.

رُصد DNS للمضيف sales.infinity-tech.sa خلال تحديث القوائم، دون استجابة DNS مرصودة. المضيف ليس في السياسة الحالية؛ HEAD سابق توقف proxy CONNECT403 / HTTP000 / curl56. المسودة الجديدة محفوظة لكنها غير مطبقة. لم تتكرر محاولة HTTP المحجوبة بلا تغير ذي صلة. لا endpoint كامل أو هوية TEST أو رفض كلمة مرور مثبت.

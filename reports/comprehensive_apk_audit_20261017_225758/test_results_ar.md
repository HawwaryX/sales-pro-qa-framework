# نتائج الاختبارات والفحوص الآلية

- خط الأساس: 54 اختبار pytest ناجحًا على Python 3.12 و3.13.
- عُرضت أربع حالات انحدار جديدة قبل الإصلاح: فشلت ثلاث ونجحت واحدة، فأثبتت قبول نوعي DTD وخطأ كتابة تقرير في الواجهة القديمة؛ الواجهة المستقلة كانت تتعامل مع خطأ الكتابة بالفعل.
- بعد الإصلاح: 58 اختبارًا ناجحًا على النسختين، دون فشل أو تخطٍ. أُكد العدد في التشغيل النهائي: 58 passed in 0.15s على3.12 و58 passed in 0.21s على3.13؛ الأدلة في evidence/pytest_python312.txt وpytest_python313.txt.
- أوامر فعلية: `.venv/bin/python -m pytest` و`PYTHONPATH=src:.venv/lib/python3.12/site-packages python3.13 -m pytest` و`.venv/bin/python -m pip check`.
- يُستخدم pytest وتبعياته النقية الحالية عبر PYTHONPATH في تشغيل 3.13؛ لم تُدّعَ بيئة Windows أو تشغيل 3.11.
- لا أوامر lint/type-check مهيأة في pyproject أو CI. فُحص المصدر بأداة Bandit إضافية معزولة ولم تُضف تبعية للمشروع.
- Bandit أبلغ خمس إشارات: B404/B603 لاستيراد subprocess واستعماله، B405/B314 لـElementTree، وB105 لقاموس حالات التقرير. ليست خمس ثغرات مؤكدة: subprocess يستخدم قائمة وسائط وأدوات موثوقة؛ قاموس الحالات ليس كلمة مرور؛ أضيف رفض DTD/ENTITY قبل XML. بقيت تنبيهات النمط في الأداة وتوثّق مراجعتها بدل إخفائها.
- pip-audit قبل تحديث البيئة: 12 سجل تنبيه في pip 25.0.1، تمثل 6 معرفات CVE فريدة وقد تتداخل سجلاتها. بعد تحديث pip إلى 26.2.1: لا تنبيهات معروفة للحزم الخارجية الست المفحوصة وقت الطلب. الحزمة المحلية غير منشورة على PyPI، فتُستثنى من قاعدة الثغرات وتُراجع كمصدر.
- pip-audit استعلم عن أسماء/نسخ حزم Python العامة فقط، ولم يُرسل APK أو بيانات التطبيق.
- لا يعني نجاح pytest نجاح وظائف Sales Pro أو أمان APK. الاختبارات المستقلة تستخدم fixtures وأدوات محاكاة، مع فحص subprocess فعلي محدود.

فحص `pip check` النهائي: No broken requirements found. فحص SHA-256 بعد التشغيل يطابق بصمة البداية. نجاح الاختبارات لا يثبت مطابقة Windows/VPS؛ هذه جلسة Linux فعلية، و3.11 لم يشغل بل فحص توافق الصياغة فقط.

فُحصت صيغة التقرير عبر CLI الاصطناعي المثبت فعلًا:

```bash
.venv/bin/sales-pro-qa --config config/sample_config.json --input examples/sample_audit.json --output /workspace/audit_work_20261017_225758/sample_smoke_ar.md
```

# خلاصة الاختبار الوظيفي لـSales Pro

الإنجاز جزئي؛ نجح التثبيت والتشغيل واستكشاف الترحيب ونموذج الدخول فعليًا على محاكي AOSP API35 يعمل برمجيًا. لم تنجح مصادقة ولم تنفذ معاملات أو تغييرات عملاء. لا يجوز اعتماد هذه النتيجة كتغطية شاملة E2E.

دفتر الحالات: **PASS: 23؛ FAIL: 4؛ BLOCKED: 54؛ NOT RUN: 3**. حالات PASS تشمل فحوص UI والبنية الاختبارية المحددة فقط؛ BLOCKED تتضمن خطط أعمال لم تنفذ، وليست فشلاً مثبتًا في وظائف التطبيق. التفاصيل في functional_test_cases_ar.md وtest_ledger.json.

## الدخول والاتصال

أُدخل الحساب النهائي الذي حدده المستخدم حرفيًا عبر واجهة التطبيق، مع استبدال الحسابات السابقة دون تجربتها كبدائل. أُرسل النموذج: **اختر الفرع والسنة المالية.** بقي فرع افتراضي وسنة فارغة، ولم يظهر منزل مصادق عليه. لا دليل على رفض كلمة المرور أو إرسال طلب مصادقة إلى الخادم.

رُصد DNS إلى sales.infinity-tech.sa أثناء تحديث القوائم. وجوده في ثلاثة libapp.so مؤكد، لكن عنوان API الكامل وهوية قاعدة TEST لم يثبتا باستجابة فعلية. السياسة الفعلية لا تشمل المضيف؛ فحص HEAD سابق توقف عند proxy CONNECT403 / origin HTTP000 / curl56. حل DNS العادي يفشل أيضًا. لم تتكرر محاولة HTTP المرفوضة بلا تغير سياسة.

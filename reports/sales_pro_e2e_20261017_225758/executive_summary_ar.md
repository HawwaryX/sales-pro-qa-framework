# خلاصة الاختبار الوظيفي لـSales Pro


## آخر تحقق API وتشغيل Android

أعادت المسارات الموجودة في APK للقوائم والشركة GET200 عبر وكيل Linux معTLS موثوق؛ ظهر الفرع والسنة المطلوبان في الردين، لكن TEST غير مثبتة. لم توجد شبكة فعالة عند قياس Android، ولم تتحقق لاحقًا جاهزية مستخدم مفتوح؛ فشلTCP للوكيل قبلTLS، ومسارADB البديل انتهى بمهلة الأداة دون حركة. تصحيح إعدادproxy قديم غير متحقق بسبب المهلات. لا دخول أو UI PASS أو أعمال جديدة؛ التراكمي29 PASS و4 FAIL و55 BLOCKED و2 NOT RUN لم يتغير. [التفاصيل والأدلة الحالية](android_connectivity_ar.md).

الإنجاز جزئي؛ نجح التثبيت والتشغيل واستكشاف الترحيب ونموذج الدخول فعليًا على محاكي AOSP API35 يعمل برمجيًا. لم تنجح مصادقة ولم تنفذ معاملات أو تغييرات عملاء. لا يجوز اعتماد هذه النتيجة كتغطية شاملة E2E.

دفتر الحالات: **PASS: 29؛ FAIL: 4؛ BLOCKED: 55؛ NOT RUN: 2**؛ 90 حالة. PASS لفحوص UI المحددة؛ BLOCKED لخطط أعمال لم تنفذ. التفاصيل في functional_test_cases_ar.md وtest_ledger.json.

## سجل الدخول والاتصال السابق

في آخر محاولة واجهة سابقة أُدخل الحساب المحدد حرفيًا، لكن **المركز الرئيسي** و**2026** لم يتاحا للاختيار؛ لم يُرسل النموذج بفرع بديل (`login_submitted=false`)، ولم تظهر جلسة مصادق عليها. [النتيجة الفعلية](evidence/followup_20261018/login_once/observations.json).

أما تقديم النموذج المذكور في الأدلة الأقدم فتوقف محليًا عند **اختر الفرع والسنة المالية**؛ لم يكن دخولًا ناجحًا بالفرع الافتراضي. لا دليل على رفض كلمة المرور، أو نقص بيانات العملاء والمنتجات، أو عيب في وظائف الأعمال. تبقى هذه الوظائف BLOCKED حتى تحميل المركز الرئيسي و2026، والتحقق من الحساب والفرع وهوية بيئة TEST قبل أي تغييرات.

رُصد DNS إلى sales.infinity-tech.sa أثناء تحديث القوائم، وثبت وجوده في ثلاثة libapp.so. اقتصر تحقق revision3 حينها على CONNECT200/TLS وHTTP404 للجذر، مع فشل DNS في Android. استُكمل الآن فحص مسارات API كما في القسم الأول؛ لم تثبت هوية TEST. CONNECT403 دليل تاريخي قبل تغير السياسة، ولا يثبت خطأ كلمة مرور.

## تشخيص Android في الدفعة السابقة

DNS الافتراضي فاشل، ووجهة التطبيق ترد عند الوكيل CONNECT403 قبل TLS مع الأصل. تجربة proxy نظامي مؤقت لم تفتح القوائم، وأعيد الإعداد الأصلي. لا مصادقة أو أعمال إضافية. تشخيص البيئة منفصل:3 PASS و4 FAIL و2 BLOCKED؛الوظائف تبقى23 PASS و4 FAIL و54 BLOCKED و3 NOT RUN.

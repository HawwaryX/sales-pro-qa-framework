# بيانات الاختبار والتنظيف

- سجلات backend المنشأة/المعدلة/المحذوفة: **صفر**. لا معاملات مالية أو عملاء حقيقيون أو اتصالات API mutations موثقة.
- بيانات نموذج اصطناعية استُخدمت لفحص الكتابة والإخفاء ولم تستخدم كحساب مصادقة بديل. لم نخمن حسابات. الحساب النهائي الذي حدده المستخدم قدم فعليًا لكن تحقق الفرع/السنة منع التقدم.
- أُفرغ حقلا النموذج فقط بعد توثيق النتيجة لحماية الصور؛ لم تُمسح بيانات التطبيق أو قاعدة cache أو secure storage أو مرحلة onboarding. اللغة عادت للعربية والاتجاه للرأسي.
- لا حاجة لحذف سجلات TEST من الخادم لعدم إنشائها؛ لا ادعاء نجاح cleanup لخادم لم نصل إليه.
- قواعد عزل IPv4/IPv6 التي أضفناها أزيلت فقط، وسلاسل Android الأصلية محفوظة. الوكيل الصحيح مستخدم، لكن ذلك لا يثبت نجاح online.
- APK الأصلي بقي بالحجم68663473 وبنفس SHA-256 قبل وبعد الفحص والتشغيل: `ae8c3cece95a8f00516045974e96749ef1fb005bfd6e86b9a0b4a1c03c667d11`؛ [الإثبات](evidence/apk_integrity_after_runtime.txt).
- ملفات فحص فارغة/مبكرة نقلت خارج مجلد التسليم؛ صور splash/ما قبل التطبيق مسماة وموصوفة، ولا تُعد نجاحًا وظيفيًا.
- المحاكي والحاوية المحلية أدوات جلسة اختبار؛ مفاتيح ADB وملفات أدوات SDK وصور النظام والتحليل الخام خارج Git. بقاء الملفات لا يعني استعادة العمليات بمهمة جديدة.

في18أكتوبر بقيت سجلات الأعمال المنشأة/المعدلة/المحذوفة صفرًا. فُرغ حقلا النموذج فقط بعد تسجيل الأدلة؛ لم تُمسح البيانات أو تُبدل الشركة أو الفرع، ولم تتغير الشبكة. لا جلسة دخول ناجحة مثبتة ولا خروج backend منفذ.

جرّب http_proxy مؤقتًا على وكيل الجلسة ثم أعيد للقيمة الأصلية. CA الجلسة استخدمت في مسبار مستقل فقط ثم حذفت نسختها من الجهاز، دون تغيير ثقة النظام أو APK أو تعطيل TLS. لا بيانات أعمال منشأة أو معدلة؛التفاصيل في تقرير الاتصال.

## تنظيف المتابعة

أُعيد font_scale من 2.0 إلى 1.0 وتحقق المشرف من ذلك؛ مُسحت النصوص الاصطناعية المملوكة للفحص فقط. لم تتغير إعدادات الشبكة أو ثقة TLS. أُنشئ مستخدم Android مؤقت لتخطي الترحيب، ثم أُعيد المستخدم الأصلي وحُذف المؤقت فقط دون مسح بيانات الأصلي. لا سجلات backend أو معاملات. [استعادة الخط](evidence/followup_20261018/ui_additional_ready/outer_guard_restore.json)؛[تنظيف المستخدم](evidence/followup_20261018/skip_isolated_user/result.json).

## تنظيف المتابعة الذاتية

لم تُدخل بيانات حساب أو معاملات أو يُنشأ مستخدم جديد. اقتصر الإيقاف على عملية Sales Pro مرة واحدة دون مسح بياناته؛ أُعيدت الشاشة إلى Awake والنموذج إلى الواجهة، وبقيت الشبكة والثقة والإعدادات دون تغيير. لا سجلات مالية لتنظيفها، ولا إعادة لاختبارات offline.

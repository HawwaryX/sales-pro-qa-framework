# استئناف التنفيذ الفعلي — 18أكتوبر2026

## النتيجة الفعلية

أُعيد تشغيل AVD الموجود نفسه بعد توقف عمليات الجلسة، دون إعادة تثبيت APK أو مسح بياناته. اكتمل الإقلاع برمجيًا على TCG في245715ms وفق سجل emulator. استُخدم الوكيل الموروث والشبكة مفعلة؛ لم يُعد العزل أو اختبار offline.

أُدخل الحساب المحدد عبر UI وتحقق تطابق اسم الإدخال حرفيًا وإخفاء كلمة المرور. طُلب تحديث القوائم والحساب مُعبّأ. أُعطيت الأداة قيمتي الفرع «المركز الرئيسي» والسنة «2026» اللتين قدمهما المستخدم، لكنها لم تجدهما قابلتين للاختيار. المتاح فرع افتراضي فقط وسنة فارغة؛ الخطأ المرئي: **تعذر تحميل الفروع أو السنوات. تحقق من الاتصال بالخادم.**

لم تُحقن قيمة أو معرف ولم يُستخدم فرع آخر. `login_submitted=false` في هذه المحاولة؛ لا يُسمى ذلك رفض كلمة مرور. تقديم النموذج في المحاولة السابقة موثق وأظهر «اختر الفرع والسنة المالية». لا شاشة منزل مصادق عليها أو هوية حساب بعد الدخول.

عند طلب الخروج، التحقق اللاحق أظهر نموذج الدخول نفسه، وليس جلسة مصادق عليها مرصودة؛ لم يُنفذ logout أو إبطال رمز backend. لا يمكن تسجيل نجاح خروج/دخول كامل.

## تشخيص الشبكة والعنوان

المضيف sales.infinity-tech.sa مرتبط بمحاولة تحميل القوائم برصد DNS السابق من التطبيق، وظهر في libapp.so. المسارات النسبية السابقة من APK محفوظة؛ لم تُركّب URL مفترضة. سجل العملية الحالي لم يُظهر طلب API كاملًا أو استجابة API أو CONNECT403: ست إشارات SocketException ومضيف خطوط Google، دون FATAL EXCEPTION أو اسم حزمة Sales Pro في crash buffer. لا تنسب أخطاء الخطوط تلقائيًا إلى API.

CONNECT403 / origin HTTP000 / curl56 نتيجة فحص HEAD السابق عبر الوكيل، قبل الوصول إلى origin؛ لم يُكرر ذلك الفحص والسياسة لم تتغير. لا redirect أو HTTP401 أو رفض حساب مثبت. لا يمكن تصنيف الخادم frontend مقابل API أو التحقق من هوية TEST باستجابة لم تصل.

**اختلاف النسخة مؤكد:** environment_status الحالي observations_current=true وrestricted/enforced revision2 لا يتيح المضيف. الإعداد المقروء من واجهة البيئة يضم القاعدة بالفعل، لكن base_version يختلف عن source_version للمهمة الحالية. [المقارنة](evidence/resume_20261018/environment_version_comparison.json). ليس المطلوب إعادة إدخال السماح أو بيانات الحساب.

المتبقي تشغيليًا: تشغيل المهمة على نسخة الإعداد التي تتضمن القاعدة أو إصلاح ربط/تطبيق النسخة على هذه المهمة بواسطة المنصة، ثم إعادة التحقق من DNS والوكيل وهوية TEST. لا تتاح هنا أداة إنشاء مهمة سحابية أو نقل الجلسة بين النسخ. لا ادعاء نشر جديد أو استعادة جديدة. لم تُعدل سياسة الشبكة خلال الاستئناف.

## إصلاح أداة الفحص

فشلت المحاولة الأولى في تهيئة UIAutomator بعد33.20ثانية، قبل إدخال الحساب أو أي تقديم؛ ليست FAIL في التطبيق. تجاوزت تهيئة TCG نافذة المكتبة الافتراضية30ثانية. أُتيح بدء90ثانية ضمن سقف مستقل240ثانية، مع انتظار idle بثانية. نجحت المحاولة التالية في121.22ثانية، وأثبتت الوصول إلى الحقول ومحاولة القوائم. COMPLETED هنا اكتمال العامل فقط، وauthenticated=false محفوظ صراحة.

أضيف مشرف subprocess دون shell يمرر الحساب عبر stdin، يحجب النصوص، ويوقف مجموعة العملية عند المهلة على POSIX. تنظيف الأنابيب له انتظار محدود. الأداة ترفض استبدال أدلة موجودة وتطابق الفرع/السنة بالقيمة الكاملة؛ لا اختيار باسم مشابه أو سنة20260 بدل2026. [التوثيق](../../docs/android-runtime-qa.md).

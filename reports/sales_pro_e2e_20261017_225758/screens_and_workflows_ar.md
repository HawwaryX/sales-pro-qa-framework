# الشاشات والمسارات التي استُكشفت

| المسار | التنفيذ الفعلي | الحدود والدليل |
|---|---|---|
| ترحيب 1–4 | عربي/إنجليزي، Next وPrevious، بدء الاستخدام | صور intro_*؛ لم يُعد التطبيق لأول تشغيل لاختبار Skip |
| الدخول | الحساب/الإخفاء/الرؤية/لوحة المفاتيح/تذكر الدخول | قيم اصطناعية لفحص الإخفاء؛ الحساب النهائي قدم لاحقًا بلا حفظ قيم |
| الفرع والسنة | عرض قائمة الفرع، محاولة السنة، تحديث، رسالة خطأ | فرع افتراضي فقط؛ [القائمة](evidence/branch_available_options.png) |
| تسجيل الدخول الفعلي | أُدخل الحساب المحدد وقدّم النموذج | [النتيجة](evidence/exact_login_result.txt)؛ التحقق المحلي يمنع التقدم |
| الاستعادة والبيومتري | ضغط فعلي ورسائل قريبًا | فجوتان موثقتان؛ لم تنفذ مصادقة بيومترية |
| الشركة والدعم والإصدار | تمرير ومشاهدة وضغط الأزرار | لا backend مختار أو مسار دعم عملي مثبت |
| اللغة ودورة النشاط | تغيير اللغة، خلفية/عودة، تدوير، Back، إعادة فتح | صور اللغة والاتجاهات؛ العودة إلى العربية والوضع الرأسي |
| المنزل والقوائم الداخلية | لم تُفتح | أسماء API/سلاسل Dart لا تثبت فتح شاشة |

لا تُحوَّل أسماء الوظائف المكتشفة في APK إلى نتائج تنفيذ. لا لقطة مصادقة ناجحة، ولا معاملة تجارية أُنشئت.

في الاستئناف أُعيدت RT-17 إلىRT-20 وRT-26: إدخال مطابق وتحديث مع الحساب ومحاولة القيم المحددة؛ لم تتاح الاختيارات. التحقق من شرط BUS-LOGOUT أظهر نموذج الدخول لا جلسة مصادق عليها، فلم ينفذ خروج أو دخول كامل. الشاشات الداخلية والأعمال49 لم تُفتح/تنفذ. [التفاصيل](resume_20261018_ar.md).

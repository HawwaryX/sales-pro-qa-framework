# Sales Pro QA Framework

A private Python QA framework for testing Sales Pro and auditing permissions against Dot X Pro.

## Overview

This repository contains:
- configuration validation
- structured test-case models
- defect tracking
- evidence manifests
- permissions comparison engine
- Arabic Markdown reporting
- synthetic fixtures
- pytest coverage
- GitHub Actions CI

## Security

- Never commit real credentials.
- Use this account only in an approved interactive environment.
- Do not perform payment or real transaction workflows.

## Limitations

This environment cannot access the local Windows Dot X Pro desktop or the Android Sales Pro app. The live audit remains blocked until an authorized interactive environment is available.
